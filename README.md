# Brackenfall 1.0 TEST
Native Java/Canvas Android 8+ Kojun-style numeric-region puzzle.

Fill each outlined three-cell room with 1, 2 and 3 once. Equal digits cannot share an edge; diagonal equals are allowed. Digits in the same room and column strictly descend from top to bottom, even if the room leaves and reenters that column. Gold clues are fixed. Tap editable cells to cycle 1, 2, 3, blank. Twelve unique clue boards share one 3x3 room layout and only two completed boards.

Saved bracken palette and fixed-clue marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java region-set, column-scan and edge-comparison oracle checks all 262144 assignments per board against production pairwise validation, confirming one solution per clue board. Fixed clues, bounds, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
